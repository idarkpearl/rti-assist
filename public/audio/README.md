# Audio Assets Directory

Drop your recorded voice notes for Yash Sehgal or Prachi Mehra here:

- **For Yash**: Name your file `yash.mp3` (or `yash.wav` / `yash.m4a`)
  - File path: `rti-assist-frontend/public/audio/yash.mp3`
- **For Prachi**: Name your file `prachi.mp3` (or `prachi.wav` / `prachi.m4a`)
  - File path: `rti-assist-frontend/public/audio/prachi.mp3`

When clicked, the avatar will automatically play this recorded voice file! If no file is present, it smoothly falls back to the browser's text-to-speech voice notes.
